# Portfolio Tracker AI Agent Skill

This skill connects Edge Gallery AI to my Supabase investment portfolio.

### How to use it:
- **To view data:** *"Hey AI, check my current portfolio and show me my stock allocations."*
- **To update a stock price:** *"Update the current price of CRDB to 680 TSh."*
- **To log a buy:** *"Record that I bought 500 shares of NMB today at 4,200 TSh."*

### Crucial Math Reminder for the AI:
- **DSE Commission Tiers:** - Sub-10M TSh = 2.06%
  - 10M–50M TSh = 1.86%
  - Over 50M TSh = 1.16%
- **Capital Gains Tax:** 10% WHT on profit only (applied to sell tranches).
